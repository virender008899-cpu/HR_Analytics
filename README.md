# HR Analytics Dashboard

## About the Project
I created this HR Analytics project to analyze employee data and understand different aspects of an organization's workforce.
The project focuses on employee demographics, department distribution, attrition, overtime, and monthly income. 
I used Microsoft Excel to organize the data, perform the analysis, answer business questions, and build an interactive HR dashboard.
-----
## Tools Used
Microsoft Excel
PivotTables
PivotCharts
Excel formulas
Data analysis and visualization
Interactive dashboard filtering
---
## Project Files
HR_Employee_Attrition_Raw.csv
This is the original employee dataset used for the project.
HR_Analytics_Dashboard.xlsx
This is the main project file. It contains the complete analysis and dashboard.
-----
## Workbook Structure
The Excel workbook contains four sheets.
Raw Data
This sheet contains the original employee data used for the analysis.
Analysis
This sheet contains the analysis performed using Excel formulas and PivotTables.
Business Questions
This sheet contains business questions related to the employee data, along with calculations, results, and insights.
HR Dashboard
This sheet contains the final interactive dashboard. It presents important HR metrics and visualizations and allows the user to explore the results by department.
--------
## Key Metrics
The dashboard includes four main metrics:
Total Employees
Total Attrition
Average Monthly Income
Average Age
----------
## Analysis Covered
The project looks at several areas of HR data, including employee distribution across departments, employee attrition, overtime, average monthly income, average age, and department-level comparisons.
--------
## Project Objective
The main objective of this project was to turn raw employee data into useful information that could help understand workforce patterns and support HR-related decision making.
